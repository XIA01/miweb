Vigía Web

Sistema de Videovigilancia P2P — Reutilizá tu celular viejo como cámara de seguridad

Probar App en Vivo GitHub

Plataforma open-source de seguridad hogareña que convierte cualquier celular viejo en una cámara de seguridad en tiempo real. Utiliza WebRTC P2P para streaming directo sin pasar por servidores, Cloudflare Quick Tunnels gratuitos para exponer cámaras IP detrás de un router, y Firebase Firestore como señalización. Soporta múltiples usuarios con cuentas independientes, PIN de vinculación y conector Windows descargable pre-configurado.

📡

WebRTC P2P — Sin servidores de video

Streaming directo de cámara a monitor vía PeerJS. El video nunca pasa por la nube: va peer-to-peer entre los dispositivos con latencia mínima y sin límite de ancho de banda.

🌐

Cloudflare Quick Tunnels — RTSP/HTTP gratis

Conector Python en Windows auto-descarga cloudflared.exe y crea un túnel HTTPS sin cuenta ni tarjeta. La URL pública se publica a Firestore automáticamente.

WiFi MDP — Radar de Conexión Libre

Radar Táctico, Brújula Satelital & Mapa de Puntos de WiFi Gratuito en Mar del Plata (Conexión MGP)

Probar App en Vivo GitHub

Aplicación web progresiva (PWA) diseñada para resolver la clásica paradoja urbana: ¿cómo buscar dónde hay internet libre si te quedaste sin datos en la calle? Utiliza el dataset oficial de Conexión MGP de la Municipalidad de General Pueyrredon y cálculos matemáticos de navegación satelital (Haversine & Bearing) para guiarte en tiempo real hacia la antena municipal más cercana sin consumir un solo mega móvil.

🛰️

100% Offline con GPS Satelital

Service Workers almacenan toda la app y las coordenadas en la memoria del celular. El GPS satelital del teléfono no requiere chip ni saldo y funciona en modo avión.

🧭

Brújula & Radar Táctico HUD

Interfaz con giroscopio y compás magnético (DeviceOrientation API). La flecha rota en vivo apuntando físicamente al punto más cercano con distancia métrica continua.

🗺️

Círculos Azules de Cobertura

Mapa nocturno Leaflet con OpenStreetMap táctico. Muestra los radios de alcance (~100m) de cada plaza, costanera o polideportivo con modo interactivo para PC.

Donaciones B1-66ER (b1.66br)

Iniciativa comunitaria gratuita y sin publicidad. Financiada mediante donaciones voluntarias con copiado directo de alias y homenaje a The Animatrix.

MDP Data Engine — API Geoespacial Serverless

Microservicios de Proximidad GPS (Haversine), Normalización UTF-8 y Contexto Territorial de Mar del Plata

Status Live

API Serverless de \$0 costo computacional y latencia inferior a 40 ms, montada sobre los 424 conjuntos de datos auditados de Mar del Plata y 209.000 geometrías normalizadas a UTF-8 estricto (reparando los errores históricos de codificación Latin-1). Ofrece cálculo de distancia esférica por GPS al vuelo y generación de resúmenes estructurados para inyección directa en ventanas de contexto de modelos de lenguaje (Claude, GPT, Gemini).

Endpoints Principales (Base: https://mdp-data-engine.vercel.app) HTTPS · JSON / Plain Text
GET /api/v1/status (Público)

Estado del motor, 51 capas disponibles, métricas de calidad y salud general.

GET /api/v1/nearest?layer={slug}&lat={lat}&lon={lon}&limit=3

Cálculo Haversine al vuelo. Devuelve los N elementos más cercanos con distancia métrica.

GET /api/v1/agent?q={termino} o ?lat={lat}&lon={lon}

Formato texto Markdown comprimido optimizado para agentes IA sin gastar tokens de más.

GET /api/v1/layer?id={slug}

Descarga vectorial GeoJSON limpia (paradas, radares, semáforos, farmacias, CAPS).
