En Producción 🔒 WebRTC P2P · Cloudflare · Multi-usuario

Vigía Web

Sistema de Videovigilancia P2P — Reutilizá tu celular viejo como cámara de seguridad

Probar App en Vivo GitHub

Plataforma open-source de seguridad hogareña que convierte cualquier celular viejo en una cámara de seguridad en tiempo real. Utiliza WebRTC P2P para streaming directo sin pasar por servidores, Cloudflare Quick Tunnels gratuitos para exponer cámaras IP detrás de un router, y Firebase Firestore como señalización. Soporta múltiples usuarios con cuentas independientes, PIN de vinculación y conector Windows descargable pre-configurado.

📡

WebRTC P2P — Sin servidores de video

Streaming directo de cámara a monitor vía PeerJS. El video nunca pasa por la nube: va peer-to-peer entre los dispositivos con latencia mínima y sin límite de ancho de banda.

🌐

Cloudflare Quick Tunnels — RTSP/HTTP gratis

Conector Python en Windows auto-descarga cloudflared.exe y crea un túnel HTTPS sin cuenta ni tarjeta. La URL pública se publica a Firestore automáticamente.

👥

Multi-usuario con PIN de 6 dígitos

Cada cuenta genera su red aislada automáticamente. Los invitados se vinculan con un PIN familiar. El conector Windows se descarga pre-configurado con las credenciales del usuario.

🔔

Detección de Movimiento con Alarma

Análisis frame-by-frame con Canvas API. Cuando se detecta movimiento activa una alarma de audio, resalta la cámara y lanza notificaciones. Umbral ajustable en tiempo real.

📱

Bento Grid Responsive con Pantalla Completa

Centro de monitoreo con grilla redimensionable tipo "Bento". Modal cinematográfico propio para pantalla completa táctil con linterna, snapshot, audio y control de cámara IP.

🐍

Conector Híbrido BAT/Python + Termux

Script Windows autoejecutable (.bat con Python embebido) y puente_termux.py para Android. Sincroniza cámaras IP RTSP en tiempo real con Firestore.

JavaScript ES6+ (Vanilla) WebRTC / PeerJS Cloudflare Quick Tunnels Firebase Firestore Python 3 (RTSP/HTTP Server) HTML5 Canvas (Motion Detection) Tailwind CSS PWA Mobile-First

En Producción ✨ Visión Artificial & Asistente IA

Diario Clínico IA

Historial Médico Familiar, Escáner de Visión por Computadora & Asistente Clínico Inteligente

Probar App en Vivo GitHub

Plataforma web médica familiar diseñada para terminar con las órdenes perdidas y el olvido de indicaciones médicas. Integra un motor propio de visión por computadora que digitaliza y endereza recetas arrugadas o tomadas de costado en el celular, junto a un asistente inteligente con IA que traduce diagnósticos a lenguaje simple y ayuda a preparar las preguntas para la próxima consulta médica.

📐

Homografía Proyectiva 2D (Perspective Warp)

Algoritmo matemático de Paul Heckbert con interpolación bilineal pixel a pixel en JavaScript puro. Endereza fotos tomadas en ángulo oblicuo a 90°, recorta la mesa de fondo y blanquea el papel en menos de 35 ms sin librerías pesadas.

🔍

Malla Táctil con Lupa de Precisión

4 anclajes magnéticos arrastrables con el pulgar. Incluye una lupa circular flotante con zoom 2.5x que aparece sobre el dedo para calzar las esquinas de la receta con precisión milimétrica sin tapar la visión.

📸

Cámara Directa & Multi-Página

Disparo directo con la cámara trasera (capture="environment") o selección de galería. Soporta hasta 5 páginas por consulta para digitalizar frente, dorso y estudios complementarios.

✨

Asistente IA (Gemini) con Persistencia

Explica qué significa cada estudio médico, formula preguntas sugeridas para el doctor y guarda permanentemente el resultado en caché local para consultarlo al instante sin gastar cuota.

🛡️

Resiliencia Móvil & Auto-Borrador

Sincronización de borrador en tiempo real en segundo plano. Si el sistema operativo del teléfono cierra la pestaña al cambiar a la cámara o WhatsApp, al volver todo el formulario se restaura intacto.

⚡

Zero-Dependencies & Ultra Ligero

Sin descargar paquetes pesados de 10 MB de WebAssembly en conexiones móviles. Todo el procesamiento de imagen se realiza de forma nativa en la GPU/CPU del navegador en tiempo récord.

JavaScript ES6+ (Vanilla) Computer Vision (Homografía 2D) Perspective Warp & Bilinear Filter HTML5 Canvas & Touch API Google Gemini AI PWA Mobile-First Tailwind CSS
